# Phase 1 playtest checklist (mobile)

Play on the phone, ideally with 2 players for PvP. For every ❌ note what happened, where,
and a screenshot. Admin chat commands (owner/Studio): `/event rain`, `/event cursed`,
`/event gold`.

## Start / UI
- [ ] Join: spawn on the pavilion, nothing clips, HUD readable (Strength, Cash, Vault income,
      day/night clock, area, objective tracker) and nothing covers the joystick/buttons
- [ ] Objective tracker walks you through: 1 LIFT → 2 FIND → 3 PICK UP → 4 COLLECT → next goals
- [ ] Menus (Collection, Vault, Shop, Ascension) open, scroll and close on a small screen

## Strength / training
- [ ] Bench prompt works; lying down hides every prompt; the bar and arms move each rep
- [ ] "+N 💪" pops each rep, PUSH speeds reps up and builds the combo, MEGA REP shows
- [ ] Joystick / ✕ gets you up; locked benches say price / Ascension needed

## Treasure discovery
- [ ] Mid-day join: a Common/Uncommon is near the gate within ~1 min (starter loot)
- [ ] Night wave: ~20 new treasures appear during the 30 s night
- [ ] Rarity readable from the look (size, glow, aura); mutations look different
- [ ] Name tag (mutation / name / rarity / $/s) only appears up close

## Carry / weight
- [ ] Pick-up hold time feels fair; heavy = slower + lower jumps; speed % in the tracker
- [ ] Strong enough → full speed or "OVERPOWERED"

## Guardians
- [ ] Wolves / goblins / spiders patrol, chase, hit, give up at their leash
- [ ] Cursed Hour: only the cursed region's guardians get tougher; purple tint only there

## PvP / knock / drop
- [ ] BONK: stable → shaken → knocked; the carrier drops the treasure
- [ ] Reclaim protection, stealing counts as a theft, safe zone protects non-carriers

## Extraction
- [ ] Standing in a zone starts the 10 s bar; a hit interrupts it; stepping out cancels
- [ ] Success: finder's fee popup "NOW EARNING $X/s", teleported home holding it
- [ ] Full Vault: "VAULT FULL • sold for $X"

## Cash / Vault
- [ ] Vault income shown in HUD; the COLLECT board outside the gate counts up
- [ ] Stepping on the green pad pays out ("💰 COLLECTED")
- [ ] Sell from the Vault menu (tap twice) and from a pedestal prompt (hold E / tap)
- [ ] Upgrade adds pedestals / floors; lift pads work; other players can't sell your stuff

## Gadgets
- [ ] Buy + equip; each of the 8 gadgets works and shows its cooldown on mobile

## Collection / Ascension
- [ ] New discoveries appear; counts correct
- [ ] Ascend when ready: Strength resets, multiplier rises, Vault and gadgets kept

## Day / night
- [ ] Warnings at 60 / 30 / 10 s; clock turns red in the last minute
- [ ] Nightfall: carried loot is lost ("LOOT LOST"), players in the Wilds are sent home,
      players in the District stay; lighting fades to a readable night and back
- [ ] Vault income x3 at night

## Events
- [ ] Treasure Rain falls in ONE region during the day; banner + arrow point there
- [ ] Gold Rush / Cursed Hour announced at nightfall for one region

## Respawn / death / persistence
- [ ] Dying while carrying drops the treasure; respawn works
- [ ] Rejoin: Cash, Strength, Vault (incl. mutations and uncollected cash), gadgets,
      Collection, Ascension all kept
